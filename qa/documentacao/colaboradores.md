Pull Request incluindo seus dados na tabela abaixo, seguindo o mesmo padrão
das linhas existentes.

## Como adicionar seu nome

1. Faça um fork do repositório e crie um branch a partir de `master`;
2. Adicione uma nova linha na tabela acima, com seu nome, um resumo da sua
   contribuição de QA e seus links de contato (GitHub obrigatório, LinkedIn
   opcional);
3. Abra um Pull Request seguindo o [guia de contribuição](./CONTRIBUTING.md).

Mantenha a ordem cronológica (colaboradores mais antigos primeiro) para
preservar o histórico de quem entrou no processo de QA em cada momento do
projeto.
